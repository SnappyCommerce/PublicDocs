# Mailchimp

## Variables

### `dc`
**Tipo:** texto

Prefijo del servidor de Mailchimp. Se obtiene directamente del API key: es la parte que aparece después del último guión.

> **Ejemplo:** si el API key es `abc123def456-us6`, el valor de `dc` es `us6`.

---

### `list`
**Tipo:** selector

Audiencia de Mailchimp a la que se agregan los contactos. Se selecciona de una lista que carga automáticamente — no requiere completar manualmente.
